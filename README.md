## 📌 Project Overview

This project aims to develop a deep learning-based model for recognizing Japanese characters, with the ultimate goal of supporting product packaging classification.

The motivation behind this project is to organize product packages based on the Japanese characters printed on them. Recognizing these characters can help identify and categorize different packages.

To achieve this goal, a Convolutional Neural Network (CNN) is implemented using PyTorch and trained on the KMNIST dataset, which contains handwritten Japanese characters across 10 different classes.

The primary focus of this project is character recognition and classification. The trained model provides a foundation for future applications in automated packaging identification and sorting.

### 🎯 Project Objectives

- Develop a CNN model for Japanese character recognition.
- Classify Japanese characters into 10 categories.
- Evaluate model performance using validation and test datasets.
- Explore the application of deep learning in supporting automated product packaging classification.
